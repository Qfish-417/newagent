## 设计决策
1. 首版先实现人工触发的完整 Agent 切片，避免调度和投递掩盖循环问题。
2. 单 Agent + 工具即可满足题意；不引入不必要的多 Agent 复杂度。
3. bash 使用受限解释器模拟常见 shell 指令，不运行任意系统 shell；后续如需通用 shell，必须采用容器隔离。
4. 首版仅供本机单用户，绑定 127.0.0.1；尚无账户系统，不可直接公开部署。
5. 新闻搜索固定过去一天，模型选择关键词和调用次数；不以硬编码顺序完成检索。
6. 当前最终简报为 Markdown，来源真实性与结构校验在 V0.2 补齐；不得宣称完整题目已完成。

每一阶段在此更新状态，使用独立 Git 提交同步到 GitHub。
