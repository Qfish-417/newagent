## 设计决策
1. 首版先实现人工触发的完整 Agent 切片，避免调度和投递掩盖循环问题。
2. 单 Agent + 工具即可满足题意；不引入不必要的多 Agent 复杂度。
3. bash 使用受限解释器模拟常见 shell 指令，不运行任意系统 shell；后续如需通用 shell，必须采用容器隔离。
4. 首版仅供本机单用户，绑定 127.0.0.1；尚无账户系统，不可直接公开部署。
5. 新闻搜索固定过去一天，模型选择关键词和调用次数；不以硬编码顺序完成检索。
6. 当前最终简报为 Markdown，来源真实性与结构校验在 V0.2 补齐；不得宣称完整题目已完成。

每一阶段在此更新状态，使用独立 Git 提交同步到 GitHub。

## 用户与每日站内调度
- 按用户记录隔离订阅、任务、简报、未读；共享同一个数据库，无需每用户一库。
- HttpOnly Cookie 匿名身份；旧数据一次性归属首个本地访问者。跨设备账号登录仍未实现。
- 用户设置每日时间与时区，UTC 存储 next_run_at；保存后立即重算并唤醒 scheduler，页面显示下次执行和差值。
- 调度到点创建任务，完成后持久化未读；点击阅读清除未读，3 秒轮询。
- 事务及唯一约束防重复；停机计划补执行一次，重启中的任务标记失败；单 worker 部署。
- 14 项测试通过，覆盖时区/跨天、改时重算、关闭、身份隔离、重复认领、恢复持久化和完成通知。生成流程用替身验证，未开启真实用户定时产生付费请求。
